# 💰 Cryptocurrency Price Tracker

A Python-based web scraping application that collects cryptocurrency prices and market data from CoinMarketCap.

## ✨ Features
- Tracks top 10 cryptocurrencies.
- Extracts coin names and symbols.
- Collects current prices and market capitalization.
- Exports collected data into a CSV file.
- Supports easy data analysis using Excel.

## 🛠️ Technologies Used
Python | Selenium | WebDriver Manager | CSV | Excel

## ⚙️ How to Run

```bash
pip install selenium webdriver-manager
python main.py
```

The extracted cryptocurrency data is saved in `crypto_prices.csv`.
